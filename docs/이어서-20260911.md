### ①②④⑦ — 약속과 코드가 갈려 있던 자리

넷 다 같은 모양이다. **문서나 프롬프트가 이미 약속한 것을 코드가 안 지켰다.**

- `.env.example` 은 `THREADS_USER_ID=` 를 빈 채로 배포하고 치트시트는
  "비워 두면 코드가 푼다"고 적어 뒀는데, `??` 는 빈 문자열을 통과시킨다.
  dotenv 가 `KEY=` 를 `""` 로 넣기 때문이다. 판정을 `env()` 한 곳에 모았다
- 프롬프트에 "겪지 않은 일을 겪은 것처럼 쓰지 마라"가 있는데도
  "2년 넘게", "고등학생 때부터"가 나왔다. 경험을 `[내 정보]` 한 줄에 끼워
  넣으니 모델이 **분위기**로 읽었다. 자기 줄로 세우고 경계선을 붙였다
- 프롬프트는 "훅 35자"를 요구하는데 재는 곳이 없었다. `MAX_HOOK_CHARS` 를
  상수로 세워 프롬프트와 검증기가 같은 값을 쓰게 했다
- `text.length` 는 `💄` 를 2, `👩‍💻` 를 5 로 센다. 이모지를 넣으려면
  이것부터 고쳐야 했다 (`countChars`)

### ② 금지만 하면 안 지킨다

이력을 막으면서 **대안을 같이 줬다.**

> 쓸 이야기가 모자라면 과거를 만들지 말고 **지금 시점**('요즘', '이번에', '어제')으로 쓴다.

금지만 하면 모델은 이야기를 세우려고 결국 어긴다. 재생성 결과에서
`고등학생 때부터 버릇이었거든` 이 `어제도 거울 보다가 못 참고` 로 바뀌었다.
같은 이야기인데 지어낸 부분만 빠졌다.

### ③ 짧은 한국어 낱말을 문자열로 넣으면 안 된다

`지성인데`·`건성인`·`복합성인`·`민감성인` 안에 `성인` 이 들어앉는다.
뷰티 계정에서 피부 타입 + `인` 은 가장 자연스러운 표현이라 계속 터진다.
실제로 검증을 통과한 글 3편이 발행 직전에 버려졌다.

키워드 목록이 정규식도 받게 하고 `/(?<![가-힣])성인/` 으로 바꿨다.
낱말이 시작하는 자리에서만 잡는다.

**그 뒤로 규칙을 넓힐 때는 반대편도 잰다.** ④의 효과 단정 정규식에는
"안 잡혀야 하는 문장" 테스트를 같이 넣었다.

### ⑤ 같은 실패를 한쪽만 못 넘겼다

쿼터 조회가 503 을 내서 `publish` 가 통째로 죽었다. 같은 URL 을 잠시 뒤
10번 부르니 10/10 성공했다 — API 가 간헐적으로 5xx 를 뱉는 구간이 있었다.
`me()` 는 그때도 정상이었으니 토큰·네트워크 문제가 아니다.

`core/publish.ts:134` 는 이미 5xx 를 일시 실패로 분류할 줄 안다. 큐 워커는
그 규칙으로 견디는데 **CLI 경로가 그 로직을 안 지나갔다.**

**POST 는 재시도하지 않는다.** 요청은 닿았는데 응답만 유실된 경우 재시도하면
글이 두 번 올라간다. 못 올리는 쪽이 두 번 올리는 쪽보다 싸다.

### ⑥ 봇 티는 타이밍에서 났다

실제로 올려 보니 본문과 첫 댓글이 **둘 다 "1분"** 으로 찍혔다.

`publish` 는 이제 본문까지만. 첫 댓글은 `.data/pending-replies.json` 에
대기로 남고 `reply` 로 나중에 단다. 20분 미만이면 "이르다", 120분을 넘기면
"묻힌다"고 말하되 막지는 않는다.

프로세스가 2시간을 들고 기다리는 방식은 쓰지 않았다. CLI 는 그렇게 오래
못 산다. 큐 워커가 생기면 `PendingReply` 를 그대로 예약 잡으로 옮긴다.
